## 🇹🇳 Building for Local Developers

My flagship project, **degachejs**, removes repeated work from Tunisian applications. It provides type-safe utilities for national IDs, bank accounts, mobile numbers and carriers, tax identifiers, currency, postal codes, and governorates.

```bash
npm install degachejs
```

The same idea is expanding beyond JavaScript through **degache-go**: useful local primitives should be easy to access in every ecosystem.

---

## 🌍 Arabic Localization & AI Agents

**Tarjemni** combines a Rust CLI with an installable AI-agent skill. It helps developers inspect projects, find source strings, plan locale switching, preserve placeholders, and detect RTL issues.

```bash
npx skills add KhalidRouissi1/Tarjemni --skill tarjmni
```
